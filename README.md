## Key Features
- Playlists
- Watch Later
- Like/Dislike
- Recently Trending
- Most-Watched
- Related Quizzes
- Dark Mode
- Type Driven Development
- Test Driven Development
- MDN like search bar
- Completely responsive
- Custom video player built using reference videos

## Tech Stack:
- ReactJS
- React-Router
- Jest
- TypeScript
